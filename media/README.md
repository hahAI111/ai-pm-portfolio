# Demo Video Assets

The captioned MP4 is published as a GitHub Release asset rather than committed to the repository, keeping the repository small.

- [Watch or download the released portfolio demo](https://github.com/hahAI111/ai-pm-portfolio/releases/download/v1.0-portfolio-demo/ai-pm-portfolio-demo-captioned.mp4)
- [Subtitle source](./ai-pm-portfolio-demo.en.srt)

To recreate the source visual video locally, run:

```powershell
python demo-video-create.py
```

Then burn the subtitle file into the MP4 with a local FFmpeg installation.
