# Marketplace Opportunity Discovery Dashboard

Working Streamlit MVP that helps a Product Manager identify and prioritize marketplace seller-growth opportunities.

## Features
- Upload marketplace data or use the included sample dataset.
- Filter opportunity analysis by category and region.
- Calculate a transparent opportunity score for each seller opportunity.
- Visualize opportunity versus GMV growth and category GMV.
- Generate a ranked backlog plus a recommended product initiative.

## Run locally

```powershell
pip install -r requirements.txt
streamlit run app.py --server.port 8502
```

## Portfolio framing
This is a data-driven PM case. It demonstrates opportunity sizing, product prioritization, business metrics, and a concrete recommendation for an AI seller-growth product roadmap.
